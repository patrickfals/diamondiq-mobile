# DiamondIQ — Task 2: Pitch-by-Pitch Replay Engine

You are working on DiamondIQ, a native Expo/React Native application built with TypeScript for an IBM Agentic AI hackathon.

Current Project

DiamondIQ is an interactive AI baseball analyst that helps fans understand real MLB at-bats through pitch-by-pitch replay, visualizations, and personalized AI commentary.

The application already retrieves historical MLB pitch data from a deployed Python FastAPI backend.

Existing components include:

src/screens/AtBatScreen.tsx

src/components/AtBatHeader.tsx

src/components/StrikeZone.tsx

src/components/PitchHistory.tsx

src/components/PitchDetailOverlay.tsx

src/types/atbat.ts

src/theme/colors.ts

The existing interface displays all pitches immediately. We want to transform it into a controlled, interactive replay that reveals the at-bat progressively.

Objective

Implement a modular pitch-by-pitch replay engine that simulates a historical MLB at-bat without revealing future events.

The replay should feel like watching the at-bat unfold rather than reviewing a completed statistical summary.

Functional Requirements

1. Sequential Pitch Replay

Begin with zero pitches revealed.

Display an initial state such as "Ready to Replay."

Add Play/Pause controls.

Automatically advance approximately every 2–3 seconds.

When Play is pressed, the first advance happens after the normal interval.

Add Previous Pitch, Next Pitch, and Restart controls.

Next, Previous, and Restart pause playback.

Restart returns to the "Ready to Replay" state, paused.

Show only revealed pitches in the strike zone and pitch history.

Display "Pitch 3" rather than "Pitch 3 of 7" during playback.

Reveal the total number of pitches only after the at-bat finishes.

Stop automatically after the final pitch.

When finished, replace Play with Replay.

Selecting Replay resets to zero revealed pitches and immediately begins playback. Restart is a separate control that resets to zero and remains paused.

2. Prevent Future Information and Spoilers

No interface component should reveal information about pitches that have not occurred in the simulation.

Specifically:

AtBatHeader must hide the final outcome until the last pitch.

Do not display final results such as "Single," "Strikeout," or "Walk" prematurely.

Hide result descriptions that would reveal the completed at-bat.

Pitch history must contain only revealed pitches.

Strike-zone markers must represent only revealed pitches.

Pitch-detail overlays must only open for revealed pitches.

Do not display the total pitch count during an unfinished replay.

No other UI component should accidentally expose future data.

Rewinding from a completed at-bat must hide the final outcome again.

The complete at-bat data may already be loaded into memory, but only currently revealed information may be rendered.

3. Accurate Baseball Count

Use the actual MLB data to determine the ball-strike count.

Verify whether the API's count_after_pitch field represents the count before or after each pitch.

Initially display 0–0.

After pitch N is revealed, display the verified count following pitch N.

Ensure rewinding restores the correct earlier count.

Do not calculate counts by naively incrementing them based only on pitch descriptions.

After the final pitch, emphasize the verified at-bat outcome rather than displaying a misleading terminal count.

Closing the overlay must not automatically resume playback.

Playback resumes only when the user explicitly presses Play.

Future pitches must remain inaccessible.

If the user rewinds or jumps to a replay position before the currently selected pitch, close its detail overlay.

### Replay Architecture

#### State Shape (`ReplayState`)

```ts
type ReplayState = {
  revealedCount: number;   // 0 = "Ready"; N = pitches 1..N visible; total = complete
  isPlaying: boolean;
};
```

`revealedCount` is the **single authoritative position**. Everything else is derived:

- `revealedPitches = allPitches.slice(0, revealedCount)`
- `isComplete = revealedCount === totalPitches`
- `currentCount = revealedCount === 0 ? { balls:0, strikes:0 } : allPitches[revealedCount-1].count_after_pitch`
- `progressLabel = isComplete ? "Pitch N of N" : revealedCount === 0 ? "Ready" : "Pitch N"`

#### Pure Reducer (`replayReducer`)

Actions: `PLAY | PAUSE | NEXT | PREVIOUS | RESTART | JUMP_TO | TICK`

```
PLAY     → isPlaying = true  (no position change)
PAUSE    → isPlaying = false
NEXT     → revealedCount = min(revealedCount+1, total), isPlaying = false
PREVIOUS → revealedCount = max(revealedCount-1, 0), isPlaying = false
RESTART  → revealedCount = 0, isPlaying = false
JUMP_TO  → revealedCount = clamp(n, 0, total), isPlaying = false
TICK     → if isPlaying && revealedCount < total: revealedCount++; if now complete: isPlaying = false
```

The reducer is a plain `(state, action) => state` function with no side effects — **fully testable without React**.

#### Playback Timer Hook (`useReplayEngine`)

- Wraps the reducer with `useReducer`.
- Holds exactly **one** `useRef<ReturnType<typeof setTimeout> | null>` for the timer.
- On each render, if `isPlaying && !isComplete`, schedules a `TICK` after a random interval in `[2000, 3000]` ms.
- Clears the previous timer before scheduling a new one (prevents duplication).
- `useEffect` cleanup clears the timer on unmount.
- `AppState` listener: on `change` → `background`/`inactive` → dispatches `PAUSE`.
- Returns: `{ state, revealedPitches, currentCount, isComplete, progressLabel, play, pause, next, previous, restart, jumpTo }`.

#### Overlay / Pitch Interaction

In `AtBatScreen`:
- `selectedPitch` is validated against `revealedCount` on every render: if `selectedPitch.number > revealedCount`, clear it.
- Opening overlay → calls `pause()` before setting `selectedPitch`.
- Closing overlay → clears `selectedPitch` only (does **not** call `play()`).
- `onPitchPress` guards: only fires if `pitch.number <= revealedCount`.

### Count-Handling Strategy

**Verification:** `count_after_pitch` is unambiguous from the field name and context. Pitch 1's `count_after_pitch` is the count that results from pitch 1 being thrown. Before pitch 1, the count is always 0–0 in baseball. I will not invent or compute counts differently — I will read exactly `pitches[revealedCount - 1].count_after_pitch` for displayed count, and `{ balls: 0, strikes: 0 }` when `revealedCount === 0`.

After the final pitch (at-bat complete), the `ReplayStatusBar` will show the **outcome** prominently instead of the terminal count, which may be misleading (e.g., a walk shows 4-0 which is technically correct but the outcome label is more meaningful).

### Timer Lifecycle and Cleanup

1. **Single ref** holds the active timer ID.
2. Every render where `isPlaying && !isComplete`, the `useEffect` clears the old timer and schedules a new one.
3. `useEffect` cleanup function always clears the timer.
4. `AppState.addEventListener('change', ...)` subscription added once on mount; removed in cleanup.
5. Play is pressed → next `TICK` fires after the full interval (not immediately).
6. Replay (from complete state) → sets `revealedCount=0, isPlaying=true` via `RESTART+PLAY` combined action → timer begins.

### Edge Cases and Risks

| Risk | Mitigation |
|---|---|
| `pitches` array is empty | `TICK` guard: `revealedCount < total`; initial state `revealedCount=0`, all derived values handle `total=0` cleanly |
| `velocity_mph` is `0` or `NaN` | `PitchDetailOverlay` already calls `.toFixed(1)` — no crash; display reads "0.0 mph" |
| `plate_x`/`plate_z` missing | TypeScript marks them required; API always provides them; `.toFixed(3)` won't crash on `0` |
| Multiple rapid taps on Play | Reducer is synchronous; `isPlaying` is already `true` on second tap → `PLAY` is idempotent |
| Timer fires after unmount | Cleanup `useEffect` clears the ref timer; React strict-mode double-mount also safe |
| API retry after replay started | `fetchAtBat` resets `atBat` → `useReplayEngine` receives new `pitches` array → `restart()` called automatically via `useEffect([atBat])` |
| `AppState` listener memory leak | Subscription object returned from `addEventListener` is removed in `useEffect` cleanup |
| `selectedPitch` stale after rewind | Derived check on every render; guard is O(1) comparison |

```typescript
import { useReducer, useEffect, useRef, useCallback } from 'react';
import { AppState, AppStateStatus } from 'react-native';
import { Pitch } from '../types/atbat';

// ─── Types ────────────────────────────────────────────────────────────────────

export interface ReplayState {
  revealedCount: number;   // 0 = ready; 1..N = pitches 1..N shown; N = complete
  isPlaying: boolean;
}

export type ReplayAction =
  | { type: 'PLAY' }
  | { type: 'PAUSE' }
  | { type: 'NEXT' }
  | { type: 'PREVIOUS' }
  | { type: 'RESTART' }
  | { type: 'REPLAY' }        // reset to 0 + immediately start playing
  | { type: 'JUMP_TO'; count: number }
  | { type: 'TICK' };         // internal: fired by timer

// ─── Pure Reducer ─────────────────────────────────────────────────────────────
// No side effects. Fully deterministic. Independently testable.

export function replayReducer(
  state: ReplayState,
  action: ReplayAction,
  totalPitches: number,
): ReplayState {
  switch (action.type) {
    case 'PLAY':
      // No-op if already complete or already playing
      if (state.isPlaying || state.revealedCount >= totalPitches) return state;
      return { ...state, isPlaying: true };

    case 'PAUSE':
      if (!state.isPlaying) return state;
      return { ...state, isPlaying: false };

    case 'NEXT':
      return {
        revealedCount: Math.min(state.revealedCount + 1, totalPitches),
        isPlaying: false,
      };

    case 'PREVIOUS':
      return {
        revealedCount: Math.max(state.revealedCount - 1, 0),
        isPlaying: false,
      };

    case 'RESTART':
      return { revealedCount: 0, isPlaying: false };

    case 'REPLAY':
      // Reset to 0 and begin playing immediately
      if (totalPitches === 0) return { revealedCount: 0, isPlaying: false };
      return { revealedCount: 0, isPlaying: true };

    case 'JUMP_TO':
      return {
        revealedCount: Math.max(0, Math.min(action.count, totalPitches)),
        isPlaying: false,
      };

    case 'TICK':
      if (!state.isPlaying || state.revealedCount >= totalPitches) {
        return { ...state, isPlaying: false };
      }
      const next = state.revealedCount + 1;
      return {
        revealedCount: next,
        isPlaying: next < totalPitches,   // stop after final pitch
      };

    default:
      return state;
  }
}

// ─── Derived values ───────────────────────────────────────────────────────────

export interface ReplayDerived {
  revealedPitches: Pitch[];
  isComplete: boolean;
  currentBalls: number;
  currentStrikes: number;
  progressLabel: string;     // "Ready to Replay" | "Pitch N" | "Pitch N of N"
}

export function deriveReplayValues(
  allPitches: Pitch[],
  revealedCount: number,
): ReplayDerived {
  const total = allPitches.length;
  const isComplete = total > 0 && revealedCount >= total;
  const revealedPitches = allPitches.slice(0, revealedCount);

  let currentBalls = 0;
  let currentStrikes = 0;
  if (revealedCount > 0 && revealedCount <= total) {
    const countAfter = allPitches[revealedCount - 1].count_after_pitch;
    currentBalls = countAfter.balls;
    currentStrikes = countAfter.strikes;
  }

  let progressLabel: string;
  if (revealedCount === 0) {
    progressLabel = 'Ready to Replay';
  } else if (isComplete) {
    progressLabel = `Pitch ${total} of ${total}`;
  } else {
    progressLabel = `Pitch ${revealedCount}`;
  }

  return { revealedPitches, isComplete, currentBalls, currentStrikes, progressLabel };
}

// ─── Hook ─────────────────────────────────────────────────────────────────────

const INITIAL_STATE: ReplayState = { revealedCount: 0, isPlaying: false };
const TICK_MIN_MS = 2000;
const TICK_MAX_MS = 3000;

function randomInterval(): number {
  return TICK_MIN_MS + Math.random() * (TICK_MAX_MS - TICK_MIN_MS);
}

export interface UseReplayEngineResult extends ReplayDerived {
  state: ReplayState;
  play: () => void;
  pause: () => void;
  next: () => void;
  previous: () => void;
  restart: () => void;
  replay: () => void;
  jumpTo: (count: number) => void;
}

export function useReplayEngine(allPitches: Pitch[]): UseReplayEngineResult {
  const total = allPitches.length;

  // Bind totalPitches into the reducer via useReducer's init
  const [state, dispatch] = useReducer(
    (s: ReplayState, a: ReplayAction) => replayReducer(s, a, total),
    INITIAL_STATE,
  );

  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

  // Clear any pending timer
  const clearTimer = useCallback(() => {
    if (timerRef.current !== null) {
      clearTimeout(timerRef.current);
      timerRef.current = null;
    }
  }, []);

  // ── Playback timer ──────────────────────────────────────────────────────────
  useEffect(() => {
    clearTimer();
    if (state.isPlaying && state.revealedCount < total) {
      timerRef.current = setTimeout(() => {
        dispatch({ type: 'TICK' });
      }, randomInterval());
    }
    return clearTimer;
  }, [state.isPlaying, state.revealedCount, total, clearTimer]);

  // ── AppState background pause ───────────────────────────────────────────────
  useEffect(() => {
    const subscription = AppState.addEventListener(
      'change',
      (nextState: AppStateStatus) => {
        if (nextState === 'background' || nextState === 'inactive') {
          dispatch({ type: 'PAUSE' });
        }
        // Deliberately do NOT resume on foreground — per requirements
      },
    );
    return () => subscription.remove();
  }, []); // runs once on mount

  // ── Reset when pitch data changes (e.g. after API retry) ───────────────────
  useEffect(() => {
    dispatch({ type: 'RESTART' });
  }, [allPitches]);

  // ── Stable action callbacks ─────────────────────────────────────────────────
  const play     = useCallback(() => dispatch({ type: 'PLAY' }),     []);
  const pause    = useCallback(() => dispatch({ type: 'PAUSE' }),    []);
  const next     = useCallback(() => dispatch({ type: 'NEXT' }),     []);
  const previous = useCallback(() => dispatch({ type: 'PREVIOUS' }), []);
  const restart  = useCallback(() => dispatch({ type: 'RESTART' }),  []);
  const replay   = useCallback(() => dispatch({ type: 'REPLAY' }),   []);
  const jumpTo   = useCallback(
    (count: number) => dispatch({ type: 'JUMP_TO', count }),
    [],
  );

  const derived = deriveReplayValues(allPitches, state.revealedCount);

  return { state, ...derived, play, pause, next, previous, restart, replay, jumpTo };
}
```

**Key design decisions:**
- `replayReducer` takes `totalPitches` as a third argument so it's a pure function (no closure over React state). It can be imported and tested directly.
- `deriveReplayValues` is also a pure exported function — testable in isolation.
- The timer effect depends on `[state.isPlaying, state.revealedCount, total]`. When any of these change, the old timer is cleared and a fresh one may be scheduled. This means NEXT/PREVIOUS/PAUSE all clear the timer immediately via the dependency change.
- `TICK` sets `isPlaying = false` on the final pitch. This causes the timer effect to not reschedule.
- `REPLAY` resets to `revealedCount=0, isPlaying=true`, which triggers the timer effect to schedule the first tick.

## Count-Handling Strategy — Explicit Walkthrough

| `revealedCount` | What we display | Source |
|---|---|---|
| 0 | **0–0** | Hard-coded (baseball always starts 0–0) |
| 1 | `pitches[0].count_after_pitch` | API data |
| 2 | `pitches[1].count_after_pitch` | API data |
| N | `pitches[N-1].count_after_pitch` | API data |
| Total (complete) | Outcome shown instead | `atBat.outcome` |

We never calculate the count by hand. We read the `count_after_pitch` field from the API verbatim. If the API represents it as "after", we show `pitches[N-1]` when `revealedCount = N` — this is correct. We rewind correctly because `deriveReplayValues(allPitches, revealedCount)` is a pure function that recomputes from any position.

  ScrollView,
  TouchableOpacity,
  ActivityIndicator,
  SafeAreaView,
} from 'react-native';
import { StatusBar } from 'expo-status-bar';
import { AtBat, Pitch } from '../types/atbat';
import AtBatHeader from '../components/AtBatHeader';
import StrikeZone from '../components/StrikeZone';
import PitchHistory from '../components/PitchHistory';
import PitchDetailOverlay from '../components/PitchDetailOverlay';
import ReplayControls from '../components/ReplayControls';
import ReplayStatusBar from '../components/ReplayStatusBar';
import { useReplayEngine } from '../hooks/useReplayEngine';
import { COLORS } from '../theme/colors';

const API_URL = 'https://diamondiq-api.onrender.com/games/777245/at-bats/1';

// Stable empty array reference — avoids re-triggering the replay reset effect
// that runs on allPitches identity change when atBat is null.
const EMPTY_PITCHES: Pitch[] = [];

type Status = 'loading' | 'success' | 'error';

export default function AtBatScreen() {
  const [status, setStatus] = useState<Status>('loading');
  const [atBat, setAtBat] = useState<AtBat | null>(null);
  const [errorMsg, setErrorMsg] = useState<string>('');
  const [selectedPitch, setSelectedPitch] = useState<Pitch | null>(null);

  // useReplayEngine receives EMPTY_PITCHES before data loads so the hook
  // initialises safely with zero pitches and no timers scheduled.
  const replay = useReplayEngine(atBat?.pitches ?? EMPTY_PITCHES);

  // Close the overlay if the user rewinds past the currently selected pitch
  useEffect(() => {
    if (
      selectedPitch !== null &&
      selectedPitch.number > replay.state.revealedCount
    ) {
      setSelectedPitch(null);
    }
  }, [replay.state.revealedCount, selectedPitch]);

  async function fetchAtBat() {
    setStatus('loading');
    setErrorMsg('');
    try {
      const res = await fetch(API_URL);
      if (!res.ok) throw new Error(`Server returned ${res.status}`);
      const data: AtBat = await res.json();
      setAtBat(data);
      setStatus('success');
    } catch (e: unknown) {
      const msg = e instanceof Error ? e.message : 'Unknown error';
      setErrorMsg(msg);
      setStatus('error');
    }
  }

  useEffect(() => {
    fetchAtBat();
  }, []);

  function handlePitchPress(pitch: Pitch) {
    // Defence-in-depth: only allow interaction with revealed pitches.
    // StrikeZone and PitchHistory already receive only revealedPitches,
    // so future pitches are never rendered as tappable elements.
    if (pitch.number > replay.state.revealedCount) return;
    replay.pause();
    setSelectedPitch(pitch);
  }

  function handleOverlayClose() {
    setSelectedPitch(null);
    // Deliberately does NOT call replay.play() — user must press Play explicitly
  }

  // ── Loading ──────────────────────────────────────────────────────────────
  if (status === 'loading') {
    return (
      <SafeAreaView style={styles.centered}>
        <StatusBar style="light" />
        <ActivityIndicator size="large" color={COLORS.accent} />
        <Text style={styles.loadingText}>Loading at-bat data…</Text>
      </SafeAreaView>
    );
  }

  // ── Error ────────────────────────────────────────────────────────────────
  if (status === 'error' || !atBat) {
    return (
      <SafeAreaView style={styles.centered}>
        <StatusBar style="light" />
        <Text style={styles.errorIcon}>⚠️</Text>
        <Text style={styles.errorTitle}>Could not load at-bat</Text>
        <Text style={styles.errorMsg}>{errorMsg}</Text>
        <TouchableOpacity style={styles.retryBtn} onPress={fetchAtBat}>
          <Text style={styles.retryBtnText}>Retry</Text>
        </TouchableOpacity>
      </SafeAreaView>
    );
  }

  // ── Success ──────────────────────────────────────────────────────────────
  return (
    <SafeAreaView style={styles.root}>
      <StatusBar style="light" />

      <ScrollView
        style={styles.scroll}
        contentContainerStyle={styles.scrollContent}
        showsVerticalScrollIndicator={false}
      >
        {/* Header: branding, matchup, inning — outcome gated on isComplete */}
        <AtBatHeader atBat={atBat} isComplete={replay.isComplete} />

        {/* Divider */}
        <View style={styles.divider} />

        {/* Replay count + progress label / outcome */}
        <ReplayStatusBar
          currentBalls={replay.currentBalls}
          currentStrikes={replay.currentStrikes}
          progressLabel={replay.progressLabel}
          isComplete={replay.isComplete}
          outcome={atBat.outcome}
        />

        {/* Playback controls */}
        <ReplayControls
          isPlaying={replay.state.isPlaying}
          isComplete={replay.isComplete}
          isReady={replay.state.revealedCount === 0}
          onPlay={replay.play}
          onPause={replay.pause}
          onNext={replay.next}
          onPrevious={replay.previous}
          onRestart={replay.restart}
          onReplay={replay.replay}
        />

        {/* Divider */}
        <View style={styles.divider} />

        {/* Strike zone — receives only revealed pitches, never future ones */}
        <StrikeZone
          pitches={replay.revealedPitches}
          selectedPitchNumber={selectedPitch?.number ?? null}
          onPitchPress={handlePitchPress}
        />

        {/* Divider */}
        <View style={styles.divider} />

        {/* Pitch history — receives only revealed pitches */}
        <PitchHistory
          pitches={replay.revealedPitches}
          selectedPitchNumber={selectedPitch?.number ?? null}
          onPitchPress={handlePitchPress}
        />

        {/* Divider */}
        <View style={styles.divider} />

        {/* AI analysis placeholder */}
        <View style={styles.aiSection}>
          <Text style={styles.aiSectionTitle}>STORY OF THE AT-BAT</Text>
          <View style={styles.aiCard}>
            <Text style={styles.aiComingSoon}>AI analysis integration coming soon.</Text>
          </View>
        </View>
      </ScrollView>

      {/* Pitch detail overlay — only opened via handlePitchPress which guards revealedCount */}
      <PitchDetailOverlay pitch={selectedPitch} onClose={handleOverlayClose} />
    </SafeAreaView>
  );
}
